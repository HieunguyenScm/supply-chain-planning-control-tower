# Project Notes

## Dashboard Purpose
This dashboard was built as a supply chain planning portfolio project to support demand review, inventory visibility, stock cover monitoring, stock rebalancing, and revenue phasing follow-up.

## Main Logic
The report follows this storyline:

Revenue signal → Demand & SKU prioritization → Inventory health → Stock rebalancing action → Revenue phasing follow-up

## Key Business Interpretation
The current dataset shows no immediate replenishment requirement because Net Demand and Order Proposal are zero. Therefore, the main planning action is to review overstock SKUs, hold unnecessary replenishment, and monitor stock rebalancing opportunities.

## Data Limitation
The dataset does not include Bill of Lading status, stock-in-transit details, or customer inventory at a transactional level. These can be added in future improvements.
